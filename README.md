# FilmajanloProject

Egy webes iskolai projekt, ami egy filmklub oldalát mutatja be. Az oldal bemutatja a klub kedvenc filmjeit, egy összehasonlító táblázatot a filmekről, a weboldal elkészülésének műhelynaplóját, valamint a felhasznált források listáját.

## Oldalak

- **Home (`index.html`)** – Kezdőlap, header szekcióval, három kiemelt film kártyával, valamint a filmklub programjainak bemutatásával.
- **Comparison (`comparison.html`)** – A három film (Oppenheimer, Interstellar, The Truman Show) összehasonlító táblázata hangulat, műfaj és filmes technika szerint.
- **Workshop (`workshop.html`)** – A weboldal fejlesztésének menetét bemutató műhelynapló, szakaszokra bontva.
- **Sources (`sources.html`)** – A projektben felhasznált képek forrásainak listája.

## Technológiák

- HTML5
- CSS3 (egyedi stíluslapok oldalanként: `style.css`, `tablestyle.css`, `workshop.css`, `sourcespage.css`)
- Vanilla JavaScript (hamburger menü, scroll-alapú megjelenési animációk)
